# Authoring templates

Copy templates into the corresponding record locations and replace neutral identifiers such as `task_001`, `hidden_state_A`, and `diagnostic_action_1`.

Fill in `TBD` fields, set the diagnostic-action budget, and link the simulator definition. Use curation metadata to track review. Trajectory records contain the observations and decisions recorded during an interaction.

Public task material belongs in `tasks/`; hidden instances and provenance belong in private storage. Validate completed records against their schemas.
